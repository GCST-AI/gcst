What it does

This project enables communication between people who use sign language and those who do not. It recognizes hand signs through a webcam and instantly converts them into readable text and spoken words. It also allows users to type text and displays the corresponding sign language gestures, making communication possible in both directions.

Why we built it

People who use sign language often face communication difficulties because many others do not understand it. This can make everyday interactions in schools, hospitals, workplaces, and public places challenging. We built this project to reduce that communication gap by providing a simple and accessible tool that translates sign language into text and speech, making conversations easier for everyone.

How it works

The user opens the web application and allows access to their webcam. The camera captures the user's hand gestures, and the system detects the hand landmarks using computer vision. A trained machine learning model analyzes these landmarks and recognizes the corresponding sign. The recognized sign is then displayed as text and can also be converted into speech. If the text-to-sign feature is available, users can also enter text, and the system displays the corresponding sign language gestures.
